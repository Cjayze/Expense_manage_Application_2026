# Expense Management Application

A personal expense management application built with Flutter. The project helps users track income and expenses, manage transactions, and monitor their financial activities through a simple and user-friendly interface.

## Features

- **User Authentication:** Register and log in using Firebase Authentication.
- **Transaction Management:** Add, view, and manage income and expense transactions.
- **Expense Categories:** Organize transactions by categories.
- **Financial Dashboard:** View an overview of personal financial activities.
- **Statistics & Charts:** Visualize income and expenses through charts.
- **Local Data Storage:** Store data locally using Hive.
- **User Profile:** Manage personal information and avatars.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Cjayze/Expense_manage_Application_2026.git
```

### 2. Navigate to the project directory

```bash
cd Expense_manage_Application_2026
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

## Requirements

- Flutter SDK
- Dart SDK (3.0.0 or later)
- Android Studio or Visual Studio Code
- Firebase project configuration
